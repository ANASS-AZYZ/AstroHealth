# Solution overview

AstroHealth connects one seeded mission simulator to:

- Mission Overview and Live Monitoring
- Astronaut Health and a synchronized Digital Twin
- Risk Alerts and AI Health Analytics
- Mission Intelligence reports, comparison, readiness, and exports
- Mission Command Center response scenarios
- Guided Demo with reversible deterministic state

The system explicitly labels simulated data, records mission events, explains response effects, and separates NASA research motivation from unvalidated software assumptions.
