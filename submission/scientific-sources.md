# Scientific sources

The project framing was checked against these accessible authoritative NASA resources:

- [NASA Human Research Roadmap](https://humanresearchroadmap.nasa.gov/)
- [NASA Behavioral Health](https://www.nasa.gov/directorates/esdmd/hhp/behavioral-health/)
- [NASA Space Radiation Element](https://www.nasa.gov/hrp/radiation/)

These sources motivate the problem context. They do not validate AstroHealth's simulator, thresholds, forecasts, readiness score, or response model.

## Integrated public dataset

- [NASA OSDR OSD-379 study page](https://osdr.nasa.gov/bio/repo/data/studies/OSD-379)
- [OSD-379 version 3 metadata ZIP](https://nasa-osdr.s3.us-west-2.amazonaws.com/OSD-379/version-3/metadata/GLDS-379_metadata_GLDS-379-ISA.zip)
- [OSD-379 public file listing](https://nasa-osdr.s3.us-west-2.amazonaws.com/?list-type=2&prefix=OSD-379/version-3/&max-keys=20)
- [NASA OSDR Open Data Registry entry and usage terms](https://registry.opendata.aws/nasa-osdr/)

AstroHealth displays verified metadata for **OSD-379 / RRRM-1 / GLDS-379**, a mouse liver RNA-seq study from Rodent Research-8 on the ISS. No numerical RNA-seq measurements are imported into the application; the existing astronaut telemetry remains simulated.

- [NASA OSDR OSD-202 study page](https://osdr.nasa.gov/bio/repo/data/studies/OSD-202)
- [OSD-202 version 10 metadata ZIP](https://nasa-osdr.s3.us-west-2.amazonaws.com/OSD-202/version-10/metadata/OSD-202_metadata_OSD-202-ISA.zip)
- [OSD-202 public file listing](https://nasa-osdr.s3.us-west-2.amazonaws.com/?list-type=2&prefix=OSD-202/version-10/&max-keys=20)

OSD-202 is a NASA-funded ground-based animal study of mice exposed to hindlimb unloading and low-dose irradiation. It is shown as research context only, not as astronaut telemetry or a source of NASA-calibrated medical predictions.
