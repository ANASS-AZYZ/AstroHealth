# Scientific sources

The project framing was checked against these accessible authoritative NASA resources:

- [NASA Human Research Roadmap](https://humanresearchroadmap.nasa.gov/)
- [NASA Behavioral Health](https://www.nasa.gov/directorates/esdmd/hhp/behavioral-health/)
- [NASA Space Radiation Element](https://www.nasa.gov/hrp/radiation/)

These sources motivate the problem context. They do not validate AstroHealth's simulator, thresholds, forecasts, readiness score, or response model.
