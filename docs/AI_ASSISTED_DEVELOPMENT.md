# AI-assisted development

AstroHealth development used an AI coding assistant through the Copilot SDK in VS Code for repository analysis, NASA OSDR source verification, implementation support, documentation, and test authoring.

The NASA study facts were checked against the public OSDR study metadata and public NASA OSDR file listing. AI assistance did not create NASA measurements, scientific results, astronaut telemetry, clinical thresholds, or NASA endorsement claims. Human review remains required for final scientific, licensing, and submission verification.
