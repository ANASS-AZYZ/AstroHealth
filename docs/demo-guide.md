# Guided Demo Guide

1. Open `/guided-demo` and choose **Start Demo**.
2. Read the mission introduction and advance through the eight steps.
3. Use the linked pages to show live telemetry, the Digital Twin, Mission Command, Risk Alerts, analytics, and reports.
4. The preset is named **Mars Crew Health Demonstration** and uses seed `7042`.
5. The preset uses the existing simulator and a controlled stress input to trigger a real configured alert rule.
6. Select a response action in Mission Command and compare the before/after indicators.
7. Use **Restart Demo** to replay the preset, or **Exit Demo** to restore the user's previous mission snapshot.

Presentation mode hides the normal sidebar and top navigation while keeping the active walkthrough visible. All values are simulated and clearly labeled.
